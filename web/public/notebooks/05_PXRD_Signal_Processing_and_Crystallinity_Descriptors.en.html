Notebook 05 — From Raw Diffractograms to Numbers a Chemist Can Interpret

A powder diffraction pattern is a curve. A curve cannot be directly sorted, filtered, correlated, or fed into a machine learning model. The inquiry "show me the syntheses exhibiting large unit cells alongside low crystallinity" is not a query a database can resolve as long as the information resides purely as a spectral profile.

This notebook builds that bridge: it transforms each raw diffraction pattern into a vector of numerical descriptors, justifying every single extracted parameter against empirical laboratory data.

How to Read this Notebook

  • Not a single raw file is opened from disk. Everything is queried from PostgreSQL via SELECT. The database serves as the single source of truth; raw instrument files scattered across directories are neither auditable nor reproducible.
  • All computational logic resides in src/pxrd_descriptors.py. This notebook imports the module rather than reimplementing functions. Consequently, the batch processing of 1,800 measurements and the diagnostic figures presented here execute identical code, eliminating any discrepancy between documentation and execution.
  • Explanatory text is written in Spanish, whilst all figures and code elements are in English. Figures are designed for direct inclusion in peer-reviewed publications or the web application.
  • Every algorithmic decision is measured, not assumed. Whenever an empirical threshold appears—an angular cut-off, a lambda parameter, or a detection limit—it is accompanied by the experiment that determined it.

1. Connection and Utilities

Three core components: sql() for database querying, cargar_curva() to retrieve a diffraction pattern already interpolated onto the canonical angular grid, and a shared plotting theme.

cargar_curva() enforces a critical safeguard: angular grid points that fall outside the instrumentally measured scan range are discarded, never extrapolated or zero-filled. Extrapolating outside the measured range would invent intensity counts at scattering angles the diffractometer never probed. The distinction between "no diffraction signal" and "unmeasured angle" must be preserved throughout the pipeline.

2. Database Inventory

Before applying any signal processing, we must establish what data is available. Two dimensions are critical: measurement counts and measurement classification tags. The distinction between sample and reference runs is fundamental: references represent the benchmarks against which all calibrations are grounded.

The four measurement families and their roles:

measurement_tag Description Methodological Role
as_synthesized Experimental laboratory samples Target corpus to be characterised
reference_blank Empty sample holder Quantifies background in the absence of sample: the instrumental zero
reference_standard Certified instrument standard Determines instrumental resolution: the minimum achievable peak width
reference_precursor Starting metal salts and unreacted ligands Non-MOF starting materials used to distinguish precursor signals from framework phases
simulated_scxrd Calculated patterns from solved single-crystal structures Benchmarks for novel phase identification and phase matching

Why blanks and standards are indispensable requirements rather than luxuries. Signal processing pipelines rely on free parameters. Selecting them simply "because literature suggests it" is an arbitrary assumption. Tuning them against specimens of known physical ground truth—an empty sample holder does not diffract; a silicon standard diffracts with known FWHM—constitutes genuine calibration. All calculations in Section 6 depend strictly on these references.

3. Why Signal Processing is Mandatory

Two diffraction scans of the exact same chemical substance can appear numerically incompatible due to acquisition artifacts unrelated to chemistry. Two major discrepancies exist across the raw dataset.

3.1 First Incompatibility: Disparate Angular Grids

What is observed. Three distributions highlighting measurement heterogeneity: start angle (2θ), end angle, and angular step size. None of these parameters is constant. The vertical axis uses a logarithmic scale in panels (a) and (c) to reveal minority acquisition protocols that would otherwise be masked by the dominant configuration—precisely the configurations that break direct vector comparisons.

Why a canonical grid is required. Point-by-point subtraction or matrix factorisation requires that point i of pattern A corresponds to the exact same scattering angle as point i of pattern B. If one scan steps at 0.0131° and another at 0.0263°, direct comparison is impossible. The solution is to resample all scans onto a canonical grid—here fixed at a step size of 0.02°, which is finer than the narrowest peak resolved by the diffractometer, preventing any loss of resolution—while clipping each scan strictly to its experimentally measured range.

Statistical considerations. Linear interpolation between measured data points is a well-conditioned estimate within the scan range: the underlying diffraction curve is continuous and the step size is dense. Extrapolation outside the measured range is physically invalid. For this reason, resample_to_grid outputs a boolean valido mask rather than zero-padding: an intensity of zero constitutes an affirmative claim ("zero diffraction counts"), which was never experimentally verified.

3.2 Second Incompatibility: Count Intensity Scales

A rapid screening scan and an overnight high-resolution Rietveld acquisition may differ in raw count intensities by a factor of 30, even when collected on the identical crystalline phase.

What is observed. In panel (a), the screening curve (red) appears flat. The material is not poorly crystalline; rather, it is plotted on the vertical scale of the blue scan, which accumulated 33 times more counts. In panel (b), dividing each pattern by its total integrated area brings both curves into near-perfect overlay. Profile shape contains the physical information; absolute peak height merely reflects detector dwell time.

Why area normalisation must precede baseline fitting. The arPLS baseline estimation algorithm applied in Section 6 incorporates a penalty parameter, λ, that governs baseline stiffness relative to the numerical magnitude of the input counts. If applied directly to raw counts, an identical λ behaves rigidly on a 200-count screening scan and flexibly on a 20,000-count pattern. Consequently, the two curves above would be treated differently due to an artifact devoid of chemical meaning. Normalising integrated area to unity first ensures that a single λ exerts an identical physical meaning across all 1,883 measurements.

4. Where the Sample Genuinely Begins: The Low-Angle Cut-Off

This section defines a single numerical boundary—the start angle of the canonical grid—which directly dictates the computed crystallinity across the entire dataset. It requires rigorous experimental justification.

4.1 The Physical Problem

At very low scattering angles, the X-ray detector directly faces the incident beam. The intensity recorded in this region does not originate from coherent sample diffraction; rather, it represents air scattering, beam spillover, and divergence slit scatter: photons reaching the detector without interacting with crystalline lattice planes. This phenomenon produces a steeply decaying low-angle tail present in every acquisition, including the empty sample holder.

If this parasitic tail enters downstream processing, baseline algorithms interpret it as a massive amorphous halo situated at the beginning of the scan. This induces artificially depressed crystallinity metrics and spuriously implies the presence of a non-existent "large unit cell".

The dilemma is not whether to truncate low angles, but at what precise angle. Three independent experiments establish the cut-off.

4.2 Experiment 1: The Median Profile of 200 Random Syntheses

If a low-angle intensity surge is present within the median profile across 200 chemically distinct MOF syntheses, it cannot represent a Bragg reflection: no cohort of 200 distinct compounds shares an identical unit cell reflection. Only the diffractometer's optical geometry is common to all 200 scans.

Each scan is normalised by its median intensity in the 20–45° region (a high-angle region devoid of intense coherent reflections) to ensure comparison of relative profile curvature rather than absolute counts.

What is observed. In panel (a), the median curve of 200 syntheses reaches 3.6 times its high-angle background at 3.0°, decaying monotonically until plateauing at 1.3 around 4.4°. The grey interquartile envelope demonstrates that this tail is universal across all specimens. In panel (b), the 11 non-porous precursor standards (inorganic salts and free ligands lacking MOF-scale unit cells) exhibit the identical parasitic tail, scaling between 3.7 and 15.5 times baseline at 3.0–3.5°, and settling to ~1 near 4.5–5.0°.

Experiment 3: The Definitive Constraint. The instrument blank and certified standard were acquired beginning at 5.0066°. Below 5°, no reference standard exists to validate signal subtraction. Processing an angular window unsupported by calibration references is unscientific.

Decision: The canonical grid begins at 5.0°, which simultaneously (a) clears the parasitic direct beam tail with a safety margin, and (b) remains fully bounded by certified calibration blanks.

4.3 The Explicit Cost of this Truncation

Bragg's law, d = λ / (2 sin θ), converts an angular boundary into a real-space lattice constraint: at the 5° 2θ cut-off with Cu Kα₁ radiation, the corresponding d-spacing is the largest the scan can resolve.

Larger interplanar d-spacings do exist—certain MOF families constructed with extended ligands yield expanded unit cells—but this laboratory diffractometer cannot resolve them. This is an instrumental constraint, not an algorithmic choice. To ensure data integrity, pxrd_descriptors maintains a boolean flag d_max_saturated, which marks patterns whose first reflection falls adjacent to 5.0°, indicating that d_max_angstrom represents a lower bound rather than an exact measurement.

The 15° "Large Unit Cell" Window (vs 10°). The orange boundary defines the angular window where large unit cell reflections are tallied. These compounds are P-MOFs (metal-phosphonate frameworks): dense networks with limited accessible pore volumes, yet exhibiting substantial unit cell dimensions due to bulky ligand cores and low-symmetry asymmetric units. Their primary diagnostic reflections appear predominantly between 10° and 15°; restricting the window to 10° would discard half of the chemically diagnostic region.

A vital semantic distinction must be stressed: prominent low-angle reflections signify a large unit cell, which merely suggests a potentially porous framework. In this chemical family, large cells arise from ligand molecular dimensions rather than solvent-accessible voids. Physical porosity is confirmed solely through gas physisorption (BET), never from powder diffraction alone.

5. Anatomy of a Powder Diffraction Pattern: Three Superimposed Layers

A diffraction pattern comprises three distinct physical contributions:

Layer Physical Origin Processing Strategy
Instrumental Background Air scatter, sample holder, detector dark noise Discarded. Carries zero chemical information
Amorphous Halo Diffuse scattering from disordered, non-crystalline solid Quantified. Measures the unreacted or non-crystalline mass fraction
Bragg Reflections Coherent diffraction from crystalline lattice planes Quantified. Defines the crystalline phase

The conventional error in materials science is treating the first two layers collectively as "background" and removing them simultaneously. This destroys the quantification of crystallization yield—the amorphous halo is primary data—and obliterates weak reflections that protrude slightly above the halo in marginal syntheses.

What is observed. In the top panel, the grey curve represents the total measured profile and the brown band illustrates the instrumental background: a featureless, monotonic baseline. In the lower panel, subtracting instrumental background isolates the sample-only signal into its two components: the broad amorphous halo (orange) and the narrow Bragg reflections (blue).

Crystallinity is defined across integrated peak and halo areas, not peak heights:

Xc = A_crystalline / (A_crystalline + A_amorphous)

Why areas rather than peak heights. Measuring peak heights relative to zero intensity double-counts the underlying amorphous halo as crystalline signal. This introduces an upward bias that scales proportionally with amorphous content, severely skewing marginal samples. Integrated areas ensure that each detected photon is allocated to one layer and one layer only.

6. Baseline Calibration of λ: The Single Free Parameter

6.1 Principles of arPLS

arPLS (Asymmetrically Reweighted Penalized Least Squares, Baek et al., Analyst 140 (2015) 250) estimates a smooth baseline beneath a 1D spectrum. The intuitive metaphor: a flexible steel wire is pushed upward from beneath the data until it makes contact with the lower envelope of the curve. λ dictates the mechanical stiffness of that wire.

  • Small λ → Flexible wire: bends sharply, penetrates narrow troughs, and engulfs the broad amorphous halo, stripping true diffuse scatter.
  • Large λ → Rigid wire: cannot conform to the natural curvature of the instrumental background, leaving residual background uncorrected.

The term "asymmetrically reweighted" represents the key mechanism: after each iteration, points lying above the fitted curve (Bragg reflections) receive near-zero weights, preventing the baseline from tracking peak contours. Weights are adjusted dynamically via a logistic function applied to negative residual deviations:

w_i = 1 / (1 + exp(2 * (d_i - (2 * sigma_neg - mu_neg)) / sigma_neg))

where mu_neg and sigma_neg represent the mean and standard deviation of the negative residuals (data points falling beneath the fitted baseline). Restricting noise estimation to negative residuals ensures that Bragg peaks do not distort baseline fitting, allowing arPLS to find the true lower floor of the spectrum rather than its mean.

6.2 Calibration via Three Ground-Truth Benchmarks

Reference Benchmark Diagnostic Question Failure Symptom
Blank (empty holder) Following baseline subtraction, does residual intensity approach zero? λ too high: leaves uncorrected background
Amorphous Sample Is the broad diffuse halo fully preserved? λ too low: baseline engulfs the halo
Crystalline Sample Do Bragg peak widths (FWHM) remain unperturbed? Baseline deforms peak profiles

All three references are drawn from the production database. The blank and crystalline samples are authentic experimental scans; the amorphous benchmark is a representative synthesis exhibiting a prominent diffuse halo.

What is observed. Evaluating the three criteria simultaneously:

  • (a) Blank residual intensity escalates sharply for λ >= 10^7: the baseline becomes excessively rigid and fails to track instrumental background decay.
  • (b) Integrated halo area collapses for λ < 10^4: the baseline bends excessively, engulfing the amorphous hump. As shown in Figure 7, the baseline climbs into the halo, spuriously inflating computed crystallinity.
  • (c) Bragg peak FWHM of the certified standard remains flat across several decades of λ, serving as an effective negative control confirming that reasonable λ values do not distort peak widths.

λ = 10^6 represents the optimal inflection point: the highest value before blank residuals escalate, whilst fully retaining the amorphous halo.

Statistical methodology. This is a single-parameter optimization balancing opposing loss functions. A unique mathematical optimum does not exist; rather, an operational plateau exists where none of the three constraints is violated. Selecting the centre of this plateau provides robust generalisation for future experimental variations.

For this reason, pxrd_descriptors logs baseline_lambda on every row: if recalibration is performed in the future, this column enables definitive identification of comparable cohorts.

7. Separating the Amorphous Halo: Three Methods and Why Only One Succeeds

7.0 Objectives and Nomenclature

Following Section 6, every pattern is resampled to the 0.02° grid, area-normalised, and assigned an arPLS baseline. We define three mathematical signals maintained throughout this document:

Profile Description Symbol Physical Meaning
Measured Scan I(2θ) Total area-normalised pattern
arPLS Baseline B(2θ) Combined background envelope
Net Signal N = I - B Signal elevated above baseline

The goal is to decompose the baseline B, which contains two physically distinct components:

B(2θ) = A(2θ) [sample diffuse scatter] + E(2θ) [instrumental background]
  • E — Instrumental Background: air scatter, sample holder, detector noise. Carries zero chemical information.
  • A — Sample Diffuse Scatter: coherent diffuse scattering from disordered solid. Directly quantifies non-crystalline sample fraction.

Three candidate methodologies were tested in chronological order:

Method Conceptual Strategy Operational Outcome
7.1 Second arPLS Pass A softer arPLS pass over N captures the halo Failed: uniformly yields zero
7.2 Rolling Width Filter Halos are broad, peaks are narrow Failed: fabricates halo under peak clusters
7.3 Instrument Blank Subtraction A = B - E, where E is directly measured Validated & deployed

All three were benchmarked against the same three reference syntheses—amorphous, incipient, and crystalline—selected based on human-curated ground truth.

7.0.1 The Three Reference Syntheses

These reference patterns are held constant across all diagnostic figures. They were selected to span the 5–50° range and represent the median case of their respective classes, avoiding cherry-picked outliers.

7.1 Method 1: Secondary arPLS Pass

Concept. If a rigid arPLS baseline isolates instrumental background E, a second, softer pass over net signal N should extract the amorphous halo A.

Mechanism of Failure. arPLS is an envelope floor estimator: it seeks the lowest boundary of data points. Net signal N = I - B already has its floor pegged at zero. Requesting the floor of a curve whose lower bound is already zero yields identically zero.

The failure is silent: it executes without raising exceptions, returning a flat zero curve. Consequently, amorphous area evaluates to zero, falsely classifying all syntheses as 100% crystalline, including visual glasses.

7.2 Method 2: Rolling Width Filter

Concept. Bragg reflections are narrow (FWHM 0.1–0.3°) while amorphous halos are broad (5–15°). A rolling median filter with a 3° window—ten times wider than individual peaks—theoretically glides over narrow peaks while following broad features.

A rolling median reflects the 50th percentile of data points in a window. If peak data points represent a minority within the 3° window, the median ignores them and tracks the underlying baseline.

This assumption was tested and found to fail catastrophically.

Failure Mode. In a purely crystalline sample displaying zero visible diffuse scatter, Method 2 allocated roughly half the pattern to amorphous content. The orange baseline rises directly beneath dense peak clusters.

The diagnostic test is straightforward: if an authentic amorphous halo existed beneath peak clusters, intensity in the valleys between adjacent peaks could not drop to zero. In empirical measurements, it does drop to zero.

Within a 3° window centred on a cluster of reflections, peak skirts dominate the distribution, causing the median to ride on peak skirts rather than baseline valleys. The premise that peaks are narrow was correct, but the prerequisite condition—that peaks constitute a minority within the window—was invalid.

Failed Patches for Method 2

Patch Strategy Proposed Concept Measured Outcome
Masking peaks and interpolating beneath Exclude peak skirts from median calculation Masking ±0.5° drops the amorphous benchmark from 0.95 to 0.42: strips genuine halos
Shifting percentile (median → 10th percentile) Track valley bottoms rather than skirts Fixes the crystalline case (0.04) but suppresses the amorphous benchmark to 0.15

Neither modification satisfies the core engineering criterion: a valid patch must resolve the failure mode without degrading previously functioning cases. Method 2 was discarded.

7.3 Method 3: Subtracting the Measured Instrument Blank

The two previous methods attempted to recognize the amorphous halo by shape alone within the specimen's own profile. Method 3 assumes nothing regarding profile geometry: it measures the diffractometer background independently and subtracts it.

Mathematical Formulation

arPLS extracts the total background baseline B, which equals the sum of both contributions:

B = A + E

An empty sample holder provides a direct experimental measurement of E: identical instrument optics, identical geometry, without sample mass. Therefore:

A = B - E

Empirical Validation of the Blank

This method is physically valid only if the instrument contributes a featureless, curvature-free background. If instrumental optics introduced curvature, subtracting it would distort genuine sample features. This is evaluated by measuring the second-derivative deviation of each baseline from a chord connecting its endpoints.

The baseline of an empty sample holder is linear within counting noise. The instrument introduces zero intrinsic curvature; therefore, all baseline curvature observed in experimental syntheses originates from the sample itself—precisely what arPLS was discarding as background.

This explains the failure of Method 1: for amorphous syntheses, arPLS had already absorbed the diffuse halo during the initial pass, because a 5–15° broad feature is smooth enough for a penalized spline to treat as baseline. The second pass found nothing because nothing remained to be found.

This mirrors the classic FTIR pitfall where baseline fitting inadvertently eliminates broad OH or NH stretching bands. The algorithm performs as designed; the error lies in expecting it to differentiate two phenomena it cannot distinguish.

Scaling the Blank Background

The empty holder and experimental syntheses were collected under different count times per step (a parameter omitted in PANalytical .xrdml headers), preventing unscaled subtraction. Both profiles are matched via an empirical scale factor k determined above 45° 2θ, where sample diffuse scatter has substantially decayed:

k = median[B(2θ > 45°)] / median[E(2θ > 45°)]

A = max(B - k * E, 0)

The median is preferred over the mean: if a residual high-angle Bragg reflection persists within the window, the mean would be skewed upward, whereas the median remains robust.

Smoothing the Blank Profile

The empty holder scan accumulated modest counts (median ~80 counts), imparting high relative Poisson noise. Scaling this raw profile upward amplifies noise, contaminating the subtraction.

Both terms must represent smooth envelopes; therefore, E is defined as the arPLS baseline of the blank, not its raw count profile.

The Denominator: Total Sample-Dispersed Scatter

To convert diffuse area A into a fractional quantity, the denominator must be physically consistent. Normalising by total scan area would incorporate instrumental background into the denominator, causing 1 - A to misclassify instrument noise as crystalline signal. The denominator must reflect total sample scatter:

A_frac = integral(A) / [integral(A) + integral(I - B)]

This definition directly resolves the question: of the total radiation scattered by this specimen, what proportion was not coherent Bragg diffraction? Its complement is rigorously the crystalline fraction, independent of variable air scatter.

7.5 Physical Meaning and Limits of the Metric

This descriptor quantifies the fraction of the diffraction pattern that is not coherent Bragg diffraction. This quantity comprises amorphous mass, alongside several physical contributions:

Contribution Physical Mechanism
Non-crystalline solid Short-range order, broad diffuse maxima
Thermal and defect diffuse scatter Present even within perfect single crystals, scaling with scattering angle
Sample substrate / zero-background plate Glass and PMMA contribute broad characteristic humps
Air scattering Primary optical path
X-ray fluorescence Fe under Cu radiation represents a prominent operational case in this laboratory

All non-Bragg contributions are grouped together deliberately. The practical takeaway must be respected:

This descriptor quantifies how much of this diffraction pattern is not Bragg diffraction, not the absolute mass percentage of amorphous material within the reaction vial.

Certified Benchmark: Silicon NIST 640

The laboratory standard is NIST 640 silicon powder, characterised by sharp reflections at 28.44°, 47.30°, and 56.12° 2θ. As a certified crystallographic standard, it represents the upper bound of crystalline perfection.

Silicon exhibits zero Bragg reflections below 28°, which is precisely where its diffuse excess appears. This is not amorphous silicon: it represents scattering from the sample mounting substrate, which the bare sample holder lacks.

Subtraction assumes that sample presentation matches the blank. Within a cohort prepared under uniform sample mounting protocols, comparisons are rigorous; across differing sample geometries, they are not.

Consequently, a PXRD crystallinity metric lacking an internal quantitative standard provides comparative rankings within a corpus, never an absolute mass percentage.

Method Detection Limit: Values Below 0.02 Do Not Represent Amorphous Mass

An intrinsic limitation emerged during interactive exploration: the arPLS baseline penetrates slightly into the base of intense Bragg peaks. Because it tracks lower envelopes, it cannot distinguish between the onset of a Bragg peak and an ascending baseline, climbing slightly up peak skirts. This misattributed area inflates computed diffuse fractions.

This was measured using a synthetic benchmark with zero amorphous content (smoothed blank background plus synthetic Gaussians of known area):

Peak FWHM Peak Area Absorbed by Baseline
0.10 – 1.00° 0.1 – 0.3%
1.50° 1.4%
2.50° 25%

On a synthetic crystalline profile containing zero amorphous mass, the pipeline returns values between 0.006 and 0.018 rather than 0.000.

Two conclusions arise:

  1. For genuine experimental peaks in this MOF corpus (median FWHM between 0.16° and 0.24°, 90th percentile below 0.57°, with zero peaks exceeding 1.0°), baseline penetration is negligible. The regime where arPLS introduces severe errors (FWHM > 1.5°) is never reached.
  2. The method possesses an intrinsic detection limit of ~0.02. Below this value, amorphous_fraction_blank cannot differentiate genuine diffuse scatter from baseline peak skirt absorption.

The median value for the CRISTALINO class evaluates to 0.011—at the detection floor. This does not indicate that these samples contain 1% amorphous phase; rather, it demonstrates that they contain zero quantifiable amorphous content. Machine learning models treating 0.011 as a continuous physical quantity would learn instrumental noise rather than chemistry.

8. Peak Detection via Poisson Counting Statistics

8.1 Why Fixed Intensity Thresholds Fail

X-ray detection is fundamentally a photon counting process. Rare, independent Poisson events in a fixed time interval obey the fundamental relation where variance equals the mean:

P(k; mu) = (mu^k * exp(-mu)) / k!
Var(k) = mu  ==>  sigma = sqrt(mu)

Noise scales with the square root of signal intensity, not as a constant percentage.

Measurement Mode Raw Count Level Expected Noise sigma Relative Noise
High-resolution scan 10,000 counts sqrt(10,000) = 100 1%
Rapid screening scan 100 counts sqrt(100) = 10 10%

A fixed intensity threshold (e.g. "detect all features exceeding 50 counts") drowns genuine peaks in rapid screening scans while falsely accepting Poisson noise in long scans. The threshold must scale dynamically as k * sqrt(counts).

8.2 Three-Sigma Governs an Isolated Test, Not a Multi-Point Scan

A 99.73% confidence interval (k = 3) denotes the probability that a single point exceeds threshold by random chance. However, peak detection is an exhaustive search across an entire scan. Evaluating 2,250 points with a 0.2° minimum peak separation yields:

n_eff = 2250 points / (9 points / 0.2°) ≈ 250

independent opportunities for Poisson noise to produce a spurious peak. At k = 3, one expects ≈ 0.7 false peaks per scan simply due to multiple testing.

Under the Bonferroni correction, maintaining an expected false-discovery rate α across the full scan requires tuning individual tests to α / n_eff:

z = Phi^-1(1 - alpha / (2 * n_eff))

Furthermore, peak detection evaluates prominence (the height of a maximum relative to surrounding local minima). Because prominence represents the difference between two noisy quantities, it carries the noise of both points (sqrt(2) * sigma):

k = sqrt(2) * Phi^-1(1 - alpha / (2 * n_eff))

Setting α = 0.05 expected false peaks per scan yields a k a little above 5 for standard acquisitions in this laboratory.

Comparability Across Heterogeneous Scans

k is not constant across all measurements: longer acquisitions present more statistical opportunities for false detection, demanding a higher prominence threshold.

This preserves comparability: what remains constant is the expected error rate across all scans. A fixed threshold would generate excess false positives in longer scans, causing peak counts to reflect collection time rather than sample crystallinity.

Empirical Noise Validation

Empirical noise was measured across the high-angle background of real scans using point-to-point first differences (divided by sqrt(2) to account for differencing variance). Experimental noise tracks the theoretical σ = sqrt(μ) line across two orders of magnitude without empirical fitting.

Parametric Bootstrap Validation

A synthetic blank containing zero Bragg peaks was generated by extracting the smoothed arPLS baseline and halo of a real sample, followed by re-injecting Poisson counting noise via np.random.poisson. At k = 3, the detector declared multiple false peaks per scan; at the calibrated k ≈ 5.1, false detections dropped to identically zero.

10.1 Traceability Descriptors (5 Columns)

These columns log the code version and parameters used during ingestion. If descriptors are recomputed with an alternative λ in the future, these columns preserve historical integrity.

10.2 Peak Geometry Descriptors (8 Columns)

n_peaks and n_peaks_k3

k = peak_k_sigma(len(x), min_distance_points)   # ~5.1-5.2 in this laboratory
peaks, widths = detect_peaks_poisson(x, net_signal, sigma, k_sigma=k)
peaks_k3, _   = detect_peaks_poisson(x, net_signal, sigma, k_sigma=3.0)
n_peaks    = len(peaks)
n_peaks_k3 = len(peaks_k3)

n_peaks represents verified reflections above the multiple-testing corrected threshold; all downstream peak parameters are derived exclusively from this set. n_peaks_k3 serves purely as a diagnostic benchmark: substantial divergence between both counts indicates a noisy amorphous pattern, whereas convergence confirms a crystalline material.

two_theta_first_peak

two_theta_first_peak = float(x[peaks[0]])

d_max_angstrom and d_max_saturated

theta_rad = np.radians(two_theta_first_peak / 2.0)
d_max_angstrom = WAVELENGTH_CU_KA1 / (2.0 * np.sin(theta_rad))
d_max_saturated = two_theta_first_peak <= LOW_ANGLE_CUTOFF_DEG + 0.10

d_max_saturated ensures models do not mistake instrumental cut-offs for physical lattice limits.

fwhm_median_deg and fwhm_min_deg

fwhm_median_deg = float(np.median(widths))
fwhm_min_deg    = float(np.min(widths))

scherrer_size_nm

beta_rad = np.radians(float(widths[0]))
scherrer_size_nm = (0.9 * (WAVELENGTH_CU_KA1 * 0.1)) / (beta_rad * np.cos(theta_rad))

Applies the Scherrer equation with shape factor K = 0.9 (paired with FWHM). It must be interpreted as a comparative index within this instrument, as instrumental broadening and microstrain are uncorrected.

10.3 Phase Composition Descriptors (10 Columns)

crystalline_area, amorphous_area, crystalline_fraction

crystalline_area     = integrate(crystalline_signal, x)   # trapezoidal integration
amorphous_area       = integrate(halo_signal, x)
crystalline_fraction = crystalline_area / (crystalline_area + amorphous_area)

Both component areas are logged alongside the dimensionless ratio. The ratio discards scale; retaining integrated areas preserves the absolute quantity of coherent scattering.

signal_snr_area and crystallinity_reliable

angular_span    = float(x[-1] - x[0])
signal_snr_area = (crystalline_area + amorphous_area) / (sigma * angular_span)
crystallinity_reliable = signal_snr_area >= MIN_SIGNAL_SNR_AREA

Evaluates whether integrated signal exceeds integrated noise across the angular range. Empty holders evaluate to 0.07, while typical syntheses range between 3 and 5.

amorphous_hump_center

amorphous_hump_center = integrate(x * halo_signal, x) / integrate(halo_signal, x)

Computes the intensity-weighted centroid of the amorphous halo. Both numerator and denominator are definite integrals; the step size cancels, yielding units of degrees 2θ.

Dimensional analysis pitfall. If the numerator were computed as a discrete sum (np.sum(x * halo)) while the denominator remained an integral, the step size (0.02°) would not cancel. The resulting centroid would be scaled by 1/0.02 = 50, outputting unphysical values exceeding 500° 2θ. Always verify homogeneity between summations and integrals.

Physically, the halo centroid reflects mean contact distances within the disordered phase: a centroid at 20–25° corresponds via Bragg's law to real-space distances of 3.5–4.5 Å, typical of dense disordered organic matrices.

amorphous_hump_fwhm

peak_halo = halo_signal.max()
above_half = np.where(halo_signal >= peak_halo / 2.0)[0]
amorphous_hump_fwhm = float(x[above_half[-1]] - x[above_half[0]])

frac_intensity_below_15deg

window = x < LOW_ANGLE_WINDOW_DEG
frac_intensity_below_15deg = integrate(normalized_scan[window], x[window])

Computes total intensity concentrated below 15° without requiring peak detection. Remains valid and physically informative in completely amorphous samples where n_peaks_below_15deg is zero.

peak_to_background_ratio

background_level = float(np.median(instrumental_background))
peak_to_background_ratio = float(np.max(crystalline_signal) / background_level)

Quantifies signal contrast above instrumental noise, reflecting collection time and sample mass.

amorphous_fraction_blank, crystalline_fraction_blank, blank_scale_factor

The core metrics introduced in v3.0, replacing legacy crystalline_fraction:

window = x >= BLANK_SCALE_FROM_DEG                     # default 45°
scale  = np.median(baseline[window]) / np.median(blank_baseline[window])
blank_scale_factor = scale

instrumental = scale * blank_baseline
amorphous    = np.maximum(baseline - instrumental, 0.0)
amorphous_fraction_blank = integrate(amorphous, x) / integrate(normalized_scan, x)
crystalline_fraction_blank = 1.0 - amorphous_fraction_blank

Normalisation across total pattern area ensures comparability across acquisitions of differing duration. This metric quantifies total non-Bragg scattering (including thermal diffuse scatter, air scatter, substrate scatter, and fluorescence), providing comparative cohort rankings rather than absolute amorphous mass percentages.

10.4 Global Descriptors (3 Columns, Peak-Independent)

These metrics remain well-conditioned in completely amorphous samples, making them ideal for ordering the entire dataset from amorphous to highly crystalline.

spectral_entropy

p = net_signal / net_signal.sum()
p = p[p > 0]
spectral_entropy = float(-np.sum(p * np.log2(p)))

Shannon entropy, H = -sum(p_i * log2(p_i)), measures intensity dispersion across angular channels.

  • Crystalline pattern → Intensity concentrated within narrow Bragg spikes → Low entropy.
  • Amorphous pattern → Intensity dispersed across a broad diffuse hump → High entropy.

Across the real corpus, correlation with crystallinity evaluates to -0.73. It must be evaluated across the net signal N, as evaluating full patterns causes featureless background to dominate, collapsing correlation to +0.04.

snr_global

snr_global = float(np.max(net_signal) / sigma)

Evaluates maximum net peak prominence in units of Poisson noise.

raw_counts_max

raw_counts_max = float(np.max(y_raw))

Recovers the absolute count scale lost during area normalisation.

The log2(N) Ceiling: Interpreting Spectral Entropy Scales

In scatter plots of entropy versus crystallinity, data points cluster near the upper boundary across all crystallinity regimes:

  1. The Logarithmic Scale. Maximum entropy for 2,250 points is log2(2250) = 11.14 bits. A crystalline pattern with 40 narrow peaks occupies 17.8% of channels, gives an entropy close to the measured median on CRISTALINO (8.46 bits), and concentrating the intensity further lowers it only slightly.
  2. Discriminative Capacity. Evaluated by Area Under the ROC Curve (AUC):
    • n_peaks: 0.994
    • crystalline_fraction: 0.973
    • amorphous_fraction_blank: 0.964
    • spectral_entropy: 0.909
  3. Effective Width Transformation. Plotting effective width 2^H * Delta (degrees) linearises the physical metric:
    • CRISTALINO: 7.1°
    • INCIPIENTE: 9.8°
    • AMORFO: 12.1°
  4. Utility. Spectral entropy provides an independent, peak-detection-free validation metric.

12. Writing to pxrd_descriptors

The database schema decouples algorithmic descriptors from human annotations:

  • pxrd_descriptors: Machine-extracted numerical features. Safe to wipe and recompute upon pipeline updates.

Records are committed via an UPSERT (ON CONFLICT DO UPDATE) keyed on measurement_id (UUID with ON DELETE CASCADE), recording pipeline_version on every row.

14. Best Practices Derived from this Pipeline

  1. An unexecuted notebook is merely a proposal. Cells with execution_count: None harbor latent errors.
  2. Calibrate against specimens of known physical ground truth. Media-hour scans of blanks and standards turn arbitrary parameter tuning into rigorous measurement.
  3. Always compute descriptors for the blank. If the pipeline attributes complex signal to an empty holder, the pipeline is flawed.
  4. Algorithms operating outside their design envelope fail silently. arPLS seeks floor envelopes; requesting a ceiling returns plausible zeroes rather than exceptions.
  5. Verify physical range boundaries. Catch unphysical angles (>180°) or fractions (>1) on day one.
  6. Beware formulas mixing summations with integrals. Step sizes fail to cancel, introducing hidden scaling factors.
  7. Simplify formulas analytically prior to deployment. Avoid duplicate, collinear columns masquerading under distinct names.
  8. Operation order is as vital as the operations themselves. Area normalisation must precede baseline estimation.
  9. Differentiate "unmeasured angle" from "zero signal". Never zero-pad unmeasured angular domains.
  10. Store pipeline versioning and parameters alongside the data. Ensure traceability across software iterations.
  11. Log measurement validity in explicit boolean flags. Flag boundary truncations (d_max_saturated) and low SNR (crystallinity_reliable).
  12. A valid hypothesis whose prerequisite condition is unverified is indistinguishable from a false hypothesis. Verify that peak skirts do not violate rolling window assumptions.
  13. Validate fixes against cases that were already working. Prevent patches from degrading valid regimes.
  14. Correct ordering does not guarantee correct quantification. Confirm absolute values against expert benchmarks.
  15. Selecting representative examples visually biases conclusions. Select canonical test cases programmatically.

Conclusions

What the database now provides: A dedicated pxrd_descriptors table containing validated numerical feature vectors for every scan, fully documented in data_dictionary and generated by a unified module (src/pxrd_descriptors.py) calibrated against certified standards.

What these descriptors do NOT represent:

  • Crystallinity is not a categorical label. It is a reproducible continuous ranking; phase purity classification resides in pxrd_labels.
  • d_max_angstrom is instrument-limited to 17.66 Å. It does not represent maximum lattice limits in the absolute chemical sense.
  • Scherrer sizes provide comparative indices, not absolute physical crystal diameters.

On Non-Negative Matrix Factorisation (NMF)

NMF decomposes a multi-scan dataset into constituent basis patterns. Its input is not reference standards, but the complete data matrix of N scans × 2,250 points. NMF learns basis components from the data itself, requiring diverse syntheses sharing identical phases. Reference standards serve distinct calibration roles.
